# Food Delivery Platform

A modern, full-stack food delivery application built with Next.js, TypeScript, and Supabase.

## Features

- 🍕 Browse restaurants and menus
- 🛒 Add items to cart
- 💳 Secure online payments and Cash on Delivery
- 📍 Location-based restaurant discovery
- ❤️ Wishlist functionality
- 📱 Responsive design
- 🌐 Multi-language support

## Tech Stack

- **Frontend:** Next.js 14, TypeScript, Tailwind CSS
- **Backend:** Supabase
- **UI Components:** Radix UI, Lucide Icons
- **Animations:** Framer Motion
- **State Management:** React Context

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/vansh33667/Food_Delivery.git
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Set up environment variables (create `.env.local`):
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. Run the development server:
   ```bash
   pnpm dev
   ```

5. Open (https://food-delivery-five-ebon.vercel.app/) in your browser.

## Project Structure

- `app/` - Next.js app router pages
- `components/` - Reusable UI components
- `contexts/` - React context providers
- `lib/` - Utility functions and data
- `public/` - Static assets
